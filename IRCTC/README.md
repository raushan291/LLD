# LLD of IRCTC System

This project implements a **Low Level Design (LLD)** of an IRCTC-like railway ticket booking system using Python and object-oriented design principles.

The goal of this project is to demonstrate **clean architecture, design patterns, and UML-driven development** rather than production-ready scalability.

## 📁 Project Structure

```css
coach_factory.py
models.py
enums.py
managers.py
request_processors.py
request_types.py
main.py
```

## ▶️ How to Run

```bash
python main.py
```
